# calculo-de-consumo-de-energia-de-eletrodomesticos-
⚡ Calculadora de Consumo Elétrico Inteligente em Python. Estima o consumo mensal em kWh e o custo em reais (R$) de aparelhos eletrodomésticos com base na potência em (Watts) e horas de uso diário. Possui validação de dados para evitar erros de digitação e tarifa padrão configurada em R$ 0,75/kWh.
